# Floe

Windows 本地专注工具。当前测试发行版 **0.1.0-beta.1**，包含 Phase 0–12 和桌面组件精简、无延时拖动。

从 [GitHub Releases](https://github.com/BernonX/floe/releases) 下载 Windows x64 自包含便携包，完整解压后双击其中的 `Floe.exe`，无需另装 .NET。关闭默认进入托盘，托盘菜单“退出 Floe”才会结束应用。[本版发布说明](docs/releases/0.1.0-beta.1.md)包含使用与升级方法。最新组件交互见 [组件精简说明](docs/widget-refinement.md)；首版开发发布、性能数据、文件清单及验证边界见 [Phase 12](docs/phase-12.md)。

## 当前可用

- 融合背景的轻量窗口控制栏，保留拖动、缩放、最小化、最大化/还原、关闭及 Windows 11 Snap 命中。
- 首页、待办、统计、设置四个页面的导航。
- MVVM、页面 DataTemplate 映射、集中式对象组装。
- Domain / Application / Infrastructure / Desktop 四层项目引用。
- 浅色、深色、跟随系统主题；使用用户提供的 floe.png 作为统一 Logo。
- 玻璃表面、计时展示控件、主/次/轻量按钮、导航、主题选项、开关和细滚动条。
- Windows 11 原生桌面 Acrylic、层次高光与柔和阴影；减少透明效果时回退为实色。
- 键盘焦点、150–220ms 按钮/卡片/页面/状态反馈；减少动态效果可立即结束正在进行的过渡。
- Ctrl+1–4 切换首页、待办、统计和设置；切页返回顶部，未保存任务草稿继续保留。
- 首页操作融合进专注卡片，默认窗口下两种计时模式与三项统计均完整显示，无需滚动。

- 番茄钟的开始、暂停、继续、跳过和重新开始；专注/短休息/长休息分段循环。
- 自定义三类时长、每轮番茄数量，以及自动进入/自动开始休息/自动开始专注。
- 基于时间锚点计算剩余时间，切页继续计时；系统睡眠后暂停，等待手动继续。
- 本次启动期间完成的番茄数量；未完成的阶段不增加数量。
- 自由计时的开始、暂停、继续和结束本次；切换模式保留暂停进度。
- 今日专注实时累计番茄与自由计时的实际投入，休息和暂停不计入。
- 两种模式运行互斥，统一记账避免重复统计；午夜按统计时区切换日期并分摊活动区间。
- Todo 新增、编辑、完成、恢复待办、删除和撤销最近一次删除。
- 待办/已完成/全部筛选，预计番茄数量、创建/完成时间、首页今日完成任务数。
- 编辑区 Enter 保存、Escape 取消、Ctrl+N 新建；任务列表使用有限高度及回收式虚拟化。
- 首页选择当前任务；番茄钟与自由计时在开始时固定任务，暂停/继续保持关联。
- 任务实时显示已完成番茄、累计专注、今日与本周专注；跳过或重新开始保留实际投入，休息不计入。
- 任务改名保留记录中的开始时标题；完成/删除不影响正在进行的记录，撤销删除恢复原进度。
- SQLite 保存任务、软删除和撤销状态、专注记录/活动区间、番茄阶段历史、每日汇总、参数与外观。
- 重启恢复原阶段、剩余时间、自由计时累计与任务归属；恢复后保持暂停，手动继续，不计入退出期间的时间。
- 运行时约每 5 秒写入检查点；命令、阶段结束、暂停、睡眠与正常退出立即保存。保存失败时暂停计时，并提供重试。
- 独立统计页：今日专注、今日完成番茄/任务，最近 7/30 天柱状图、期间合计和每日平均。
- 图表按连续日历日期补零，包含今天；点击或用左右方向键查看单日番茄/自由时长。日均包含未专注的日期，统计页只在可见期间订阅实时更新。
- 桌面 Widget：无普通标题栏、圆角、拖动、置顶、位置锁定及显示/隐藏，配置与位置自动保存；玻璃透射由设计系统控制，无用户透明度参数。
- Widget 复用主程序番茄/自由计时与任务归属；隐藏不停止计时，主窗口最小化时仍显示，点击主体直接恢复到首页，按住鼠标移动即可拖动，无长按延时。
- Widget 默认关闭，在设置开启；关闭组件只隐藏。主窗口默认关闭到系统托盘，专注继续计时；托盘或设置中的“退出 Floe”保存并退出所有窗口。
- Widget 仅保留时间、当前任务和 ×，宽 240 DIP；紧凑模式在设置页选择并保存。尺寸过渡支持快速反向；显示/隐藏立即完成以保留原生 Acrylic。
- 原生系统托盘菜单：打开主窗口、开始/暂停/继续番茄钟与自由计时、显示/隐藏组件、退出。两种计时继续保持互斥；恢复窗口保留最大化状态。
- 自然结束的专注、休息与成功保存的任务完成操作触发系统提醒。提醒与声音独立控制，声音默认关闭；跳过、重启阶段、恢复历史不误发提醒。
- 设置关闭/最小化到托盘、登录 Windows 后启动。开机启动默认关闭，启用后在当前用户登录时后台驻留，使用 Windows 注册表启动项，不需要管理员权限。

数据默认保存在 `%LOCALAPPDATA%\Floe\floe.db`，设置页可查看实际路径。正常退出会保存最后的实际投入；强制结束进程或崩溃只恢复最近成功提交的检查点，健康磁盘且调度正常时未保存尾段约在 5 秒内。存储失败、磁盘故障或长时间调度停顿会超出该范围。首页“本次完成番茄”重启回零，统计页的今日完成番茄和任务累计保留。统计时区在首次创建数据库时取系统时区并保存，后续启动保持该时区，本周从周一开始；现阶段不提供时区切换。专注按活动区间跨日分摊，完成番茄按结束日期计数。

## 环境

- Windows 11 x64 已完成桌面验证；Windows 10 已实现视觉回退，尚未做实机验收，需同时确认系统版本受 .NET 10 支持。
- .NET SDK **10.0.401**（同功能带的后续补丁由 `global.json` 允许）。
- 首次还原需要访问 NuGet.org。

本工作区已将微软官方 SDK 解压到 `.tools/dotnet`；该目录忽略提交，未修改系统安装或 PATH。其他机器可以安装匹配的官方 SDK。`scripts/dotnet.ps1` 优先使用本地 SDK，否则使用系统 `dotnet`，并将 CLI 缓存与 NuGet 包放在 `.tools`。

## 构建与运行

在 PowerShell 中进入项目目录：

```powershell
git clone https://github.com/BernonX/floe.git
cd .\floe
.\scripts\dotnet.ps1 restore .\Floe.sln --locked-mode --configfile .\NuGet.config
.\scripts\dotnet.ps1 build .\Floe.sln -c Release --no-restore
.\scripts\dotnet.ps1 run --project .\src\Floe.Desktop\Floe.Desktop.csproj -c Release --no-build
```

如果本机脚本策略阻止执行，可对单次调用使用 `powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\dotnet.ps1 ...`，不需要修改全局执行策略。

正常开发构建仍为框架依赖，输出在原 `src/Floe.Desktop/bin/Release/net10.0-windows`。只有系统 .NET 8 的机器使用上述脚本运行，它会定位工作区 .NET 10；自包含预览包包含运行时，可以直接双击 EXE。发布包是目录/ZIP，没有安装程序，DLL 需与 EXE 一起保留。

也可以使用支持 .NET 10 的 Visual Studio 打开 `Floe.sln`，将 `Floe.Desktop` 设为启动项目。

## 手动验收

1. 启动后出现首页，顶部控制区域融入背景，右上角可最小化、最大化和关闭；顶部无图标或单独标题栏。
2. 依次点击待办、统计、设置、首页；页面标题与正文同步变化。
3. Tab 进入导航后用上下方向键切换，焦点清晰可见。
4. 缩放到最小尺寸、最大化并还原，内容不被裁掉；较小高度可滚动。
5. 打开“设置”，切换浅色、深色和跟随系统；确认文字、卡片、按钮和窗口同步变化。
6. 开启减少透明效果及减少动态效果，再恢复默认；核对实色表面与即时反馈。
7. 设置三类时长为 1 分钟，每轮数量为 1，启用自动开始休息并应用。返回首页开始；切页后仍计时，暂停后保持，继续后接着计时，重新开始回到 01:00。
8. 完整等待一分钟，应增加一个完成番茄并自动进入长休息；跳过休息回到下一轮，跳过专注不增加完成数。
9. 进行中修改参数，当前轮保持原参数，下一轮使用新参数。关闭自动进入后，阶段结束等待手动进入。
10. 暂停番茄钟，切换首页的“自由计时”。开始后本次与今日合计增长；暂停后保持；继续后接着累计。
11. 自由计时运行时，番茄钟开始/跳过按钮禁用，并显示原因；反向切换也需先暂停。切换显示模式本身不会暂停或开始。
12. 点击“结束本次”，本次回零，今日累计保留。跨午夜时今日日期与合计进入新一天，本次累计继续；跨日测试也可使用下方可控时间测试完成，不必改系统时间。
13. 待办页添加标题及预计番茄；标题必填、最多 120 字，预计数量 0–99，0 表示不设预计。空标题、非整数及超范围输入不能保存。
14. 编辑任务后保存或取消；使用 Enter 保存、Escape 取消、Ctrl+N 新建。切页保留任务、筛选和未保存草稿。
15. 勾选任务完成，在“已完成”中取消勾选恢复待办。首页“今日完成任务”随状态变化更新。
16. 删除任务后点击撤销删除；任务 ID、预计数量与原完成状态应保留。较多任务可在列表内滚动，小窗口还可滚动整页。
17. 首页选择任务后开始番茄钟，暂停/继续期间任务选择锁定；重新开始当前阶段后可以换任务。休息期间可选择下一次专注的任务。
18. 完成一分钟专注后，任务增加一个番茄及一分钟专注；跳过、重新开始和自由计时只累计实际投入，不增加番茄。任务今日时间应与属于该任务的两种计时之和一致。
19. 结束自由计时后可换任务；若另有暂停的番茄专注，需先重新开始该阶段以结束旧记录。删除正在专注的任务后首页显示已删除，记录仍归原 ID；撤销删除后进度保留。完成任务不会自动结束计时，也不会自动分配给下一次专注。
20. 更改主题、减少透明/动态效果及番茄参数，运行一次绑定任务的计时，再从托盘菜单“退出 Floe”。重新打开后任务、累计和设置保留，计时暂停；继续后接着累计，离线时间不增加。
21. 自由计时至少运行 6 秒后强制结束本次测试进程，重新打开应恢复最近检查点并保持暂停；继续后不重复累计之前的时间。
22. 删除任务后退出并重开，可撤销最近一次删除，任务 ID 和原进度保留。设置页显示实际数据库路径。数据库损坏、较新版本或无法写入时会报错并保留原文件，不会自动清空重建。
23. 统计页切换 7/30 天，核对今日时长与首页一致、期间合计及日均、空白日期补零；选择柱或使用左右方向键查看单日两种计时明细。运行时实时增长，暂停后保持，今日完成番茄跨重启保留。
24. 设置页开启桌面组件，在首页或托盘开始/暂停计时，核对组件时间与当前任务。按住组件主体直接拖动，开启锁定后禁止移动，重置位置仍保留锁定。
25. 组件切换置顶，最小化主窗口后组件继续显示；点击时间、任务或留白直接打开首页。× 或 Alt+F4 只隐藏组件，再次显示使用最新状态，拖动松手不打开主窗口。
26. 保持组件显示后退出并重开，核对位置、锁定、置顶、紧凑模式及暂停计时。减少透明效果时组件回退实色；显示器改变时位置自动恢复到工作区域。
27. 关闭主窗口，确认进程仍驻留且组件与计时继续；右击通知区域的 Floe 图标，操作计时、显示/隐藏组件并恢复主窗口。最大化后最小化到托盘，再打开应恢复最大化。
28. 在设置中测试提醒、切换声音和通知；自然结束专注及休息、完成任务应提醒，跳过、重启、重开应用不补发。Windows 勿扰与通知策略可能阻止显示，系统音量可能静音。
29. 按需启用开机启动后在 Windows 启动应用列表核对 Floe，重新登录后应驻留托盘；关闭选项后移除 Floe 启动项。开发目录需要保持原位置及运行时可用，不要为测试无意启用真实启动项。
30. Ctrl+1–4 切页，确认页面不叠加、滚动返回顶部，待办草稿保留。按钮、卡片及计时状态有短暂反馈，普通秒数更新保持静止。
31. 在设置中切换“紧凑模式”，确认组件计时和任务无裁切且归属保持。快速连续切换，再开启减少动态效果，应立即到达最终布局；重启保留紧凑与锁定选项。

## 本地数据

- 默认目录：`%LOCALAPPDATA%\Floe`。可以在独立 PowerShell 进程设置 `$env:FLOE_DATA_DIRECTORY = 'E:\Codex\floe\artifacts\my-data'` 后运行，用于测试或便携数据目录；应用按目录限制一个实例。
- `floe.db-wal` / `floe.db-shm` 是 SQLite 正常运行文件，`floe.lock` 用于避免两个应用覆盖同一检查点，退出后释放锁，文件可以保留。
- 手动备份前先正常退出 Floe，再复制整个数据目录；运行时不要仅复制主数据库，也不要修改或删除锁文件。自动备份、导入/导出和云同步尚未实现。
- 所有 SQL 数据使用参数，事务同时写专注记录和恢复检查点。schema 使用 `PRAGMA user_version` 顺序迁移，拒绝降级打开较新结构。
- 基于 [Microsoft.Data.Sqlite 10.0.12](https://www.nuget.org/packages/Microsoft.Data.Sqlite/10.0.12)，没有引入 ORM。锁定文件包括其 SQLitePCLRaw 原生运行依赖。
- 当前 schema 4，系统提醒与托盘选项保存在独立表；旧库自动顺序迁移，主题、Widget 与系统设置互不覆盖。开机启动以 Windows 当前用户的启动项为准，不在数据库重复存储标志。

## 工程约束

- Domain 无 UI、数据库、Windows 平台依赖。
- Application 仅引用 Domain；Infrastructure 实现平台和存储适配。
- Desktop 通过 CompositionRoot 组装依赖；MainWindow 不承载业务规则。
- 计时规则位于 Domain，串行协调与调度位于 Application，Windows 时钟位于 Infrastructure；页面只消费快照与发送命令。
- 依赖版本集中在 `Directory.Packages.props`，锁定解析结果到各项目 `packages.lock.json`。
- 每一阶段完成后停止，确认后再继续下一阶段。
