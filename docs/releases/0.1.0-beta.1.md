# Floe 0.1.0-beta.1

发布日期：2026-10-01。首个测试发行版，Windows x64 自包含便携包。

## 使用方法

1. 完整解压 `Floe-0.1.0-beta.1-win-x64.zip`。
2. 打开解压目录，双击 `Floe.exe`，无需另装 .NET。
3. 不要仅复制 EXE，旁边的 DLL 和运行时文件需一同保留。
4. 默认关闭主窗口会驻留系统托盘；托盘菜单或设置中的“退出 Floe”保存并结束程序。

## 包含功能

- 自定义番茄专注、短休息、长休息及分段循环，支持开始、暂停、继续、跳过与重新开始。
- 独立自由专注计时；与番茄计时互斥，统一计入每日专注。
- Todo 管理、任务绑定、专注记录与最近 7/30 天统计。
- SQLite 本地保存、检查点恢复；重启后保持暂停，不累计离线时间。
- 浅色、深色及跟随系统主题，玻璃界面与集成窗口控制栏。
- 精简桌面组件，仅显示时间、当前任务和 ×；单击回到首页，按住鼠标移动即拖动，无长按延时。
- 系统托盘、提醒、声音与开机启动设置；开机启动默认关闭。

## 数据与升级

数据默认保存在 `%LOCALAPPDATA%\Floe`，主数据库为 `floe.db`；设置页显示实际路径。程序目录可以移动，数据默认不会随之移动。本包不包含个人数据库。

从预览版升级：先通过托盘“退出 Floe”，备份整个数据目录，再运行本版。数据结构保持 schema 4，不清空历史任务、专注记录或设置。

备份前正常退出程序，再复制整个数据目录。运行时不要只复制主数据库，也不要删除 SQLite 的 WAL/SHM 或实例锁文件。若启用了开机启动并移动了程序路径，请从新位置关闭再开启启动选项。

诊断日志位于数据目录的 `logs`，保留两份轮换日志。提交问题时可提供版本、操作步骤和日志；分享前检查日志中的本机路径。

## 本版验证范围

已在 Windows 11 x64、150% DPI 桌面验证。已有 146 项 Domain/Application/Infrastructure 自动测试通过；桌面回归覆盖真实一分钟番茄、任务绑定/统计、退出保存失败重试、崩溃检查点恢复、主题、托盘与组件。测试发行版另执行发布 EXE 的 UI 与组件手势回归，核对包内运行时和 ZIP 校验。

Windows 10 的视觉回退已实现，但尚未做 Win10 实机验收；多屏混合 DPI、高对比完整操作与数小时稳定性测试也尚未完成。完整开发验证历史在项目 `docs` 中保留。

这是未签名测试版，当前为目录/ZIP 发布，没有安装程序或自动更新。组件保持可调整的置顶、锁定和紧凑设置。自动备份、导出、账号及云同步尚未实现。

## 校验

压缩包旁的 `.sha256` 用于检查 ZIP 的 SHA-256，包内 `SHA256SUMS.txt` 记录逐文件哈希。包内 `release.json` 列出版本、平台、运行时和数据结构版本；`notices` 包含随附依赖的许可及通知。
